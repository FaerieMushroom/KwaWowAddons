# KwaMiscUtilities

Miscellaneous utility plugin for **KwaLite** on **WoW Forever (16001)**. Requires the `KwaLite` addon.

## Features

- **Time to Level minimized view** — an optional compact entry in the Kwa Lite minimized bar showing an estimated time to the next level. The tracker only runs while this view is enabled.
- **Auto share newly accepted quests** — optional, disabled by default. When enabled, shareable quests you accept are pushed to your party or raid. Works only while grouped and never in a battleground.

## Usage

- `/kwa` or `/kwalite` opens the Kwa Lite window.
- Select the **Misc Utilities** plugin from the right-side icon bar.
- Tick **Time to Level** under **Minimized Displays** to show the compact time-to-level readout while Kwa Lite is minimized. Unticking it stops the XP tracker entirely.
- Tick **Auto share newly accepted quests** under **Functionality** to share new quests with your group.
